下面列的是这个项目真正用到、也真心推荐的开源项目：

## 终端

- [oh-my-posh](https://ohmyposh.dev) —— 跨 shell 的提示符主题引擎，工具内置了它的 6 个主题
- [fastfetch](https://github.com/fastfetch-cli/fastfetch) —— 系统信息面板，启动时一眼看清机器状况
- [Nerd Fonts](https://www.nerdfonts.com) —— 带图标的等宽字体，工具内置 MesloLGS NF
- [Windows Terminal](https://github.com/microsoft/terminal) —— 很好用的终端，**可惜在 Server Core 上装不了**（见[实测记录](../posts/windows-terminal-on-server-core/)）

## 系统管理

- [Windows Admin Center](https://learn.microsoft.com/windows-server/manage/windows-admin-center/overview) —— 微软官方的 Web 管理台，工具支持一键部署
- [Server Core 文档（Microsoft Learn）](https://learn.microsoft.com/windows-server/administration/server-core/server-core-administer) —— Server Core 的官方管理说明

## 本站

- [Astro](https://astro.build) —— 本站的构建框架
- [Mizuki](https://github.com/matsuzaka-yuki/Mizuki) —— 本站使用的主题（MIT 许可）
