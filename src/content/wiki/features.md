## 系统的 21 个工具入口

「系统工具」页列的是**系统自带工具**的入口，按本机实际有没有自动灰显：

- 常用 7 个：记事本、命令提示符、美化终端、MMC 控制台、资源监视器、系统信息、PowerShell ISE
- 另外 14 个（服务 / 事件查看器 / 磁盘管理 / 注册表 …）收在「Windows Admin Center 里也有」一组里，**默认收起**

本机**没有**的工具会标上「（缺失）」并变浅色，但**点它照样有反应** —— 会说明缺什么、去哪补，并问你要不要用命令提示符代替。装好 WAC 并在运行时，重复的那一组会**整组隐藏**。

## 附属工具

「SCM附属」页管理三套可以独立运行的工具，源码在 GitHub 的独立分支，发行包同时放在 GitHub 与 Gitee：

| 工具 | 内容 | 获取 |
|---|---|---|
| **scterm** | Rust 单文件终端多路复用 | `tool/scterm` 分支 ｜ `scterm-v0.1.0` 发行包 |
| **scm-top** | 零依赖 TUI 监控（PowerShell） | `tool/tuimonitor` 分支 ｜ `scm-top-v0.1.0` 发行包 |
| **CraftDock** | TypeScript 终端服务器管理 | `tool/craftdock` 分支 ｜ `craftdock-v1.0.0` 发行包 |

页面里选中一行即可从 GitHub 或 Gitee 下载发行包，解压到 `payload\plugins\<工具>`；已安装时整体替换，失败保留旧版本。
