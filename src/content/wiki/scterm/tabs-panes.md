## 标签页

| 操作 | 方式 |
|---|---|
| 新建标签 | `Ctrl+B`（默认 profile） |
| 新建并选择 profile | `Ctrl+Shift+B`，或 `Alt+点标签栏的 +` |
| 关闭标签 | `Ctrl+Shift+W`、中键点标签、点标签末尾的 `×` |
| 切换标签 | `Ctrl+Tab` / `Ctrl+Shift+Tab`，或在标签栏滚轮 |
| 直达标签 | `Ctrl+1` ~ `Ctrl+8`，`Ctrl+9` 最后一个 |
| 重命名 | `Ctrl+Shift+R` |
| 拖动重排 | 在标签栏按住左键左右拖 |

- 标签末尾的 `×` 是独立的 3 列区域，整块都能点；`+` 是 3 列宽的绿色按钮，和标签空一格。
- 关闭标签前是否确认由 `confirm_close` 控制（默认开启）；中键与 `×` 走同一套确认逻辑。
- 后台标签收到响铃显示 `!`；上一条命令成功显示 `✓`，失败显示 `✗退出码`。切到该标签即清除响铃。

## 窗格

| 操作 | 方式 |
|---|---|
| 左右分屏 | `Alt+Shift+-` |
| 上下分屏 | `Alt+Shift+加号` |
| 移动焦点 | `Alt+方向键`（按几何中心找最近窗格） |
| 放大 / 还原聚焦窗格 | `Ctrl+Shift+Z` |
| 与相邻窗格交换 | `Ctrl+Shift+Alt+方向键` |
| 把窗格移到新标签 | `Ctrl+Shift+Alt+T` |
| 调整分隔线比例 | `Alt+Shift+方向键`（每次 5%），或直接拖分隔线 |
| 关闭窗格 | 命令面板里的「关闭窗格」，可自行绑定快捷键 |

- 窗格树支持任意嵌套，比例范围 5%–95%。
- 分隔线占 1 列/1 行，与聚焦窗格相邻的分隔线用高亮色。
- 关闭窗格时父节点折叠为兄弟节点；最后一个窗格关闭即关闭标签，最后一个标签关闭即退出。
- 放大模式下只有聚焦窗格占满内容区，其余窗格暂时隐藏，分隔线不可拖。

## 标签栏与状态栏

- 标签栏固定在第 0 行，标签标题格式为 `序号:名称`。
- 状态栏固定在最下面一行：
  - 左侧常驻快捷键提示，按可用宽度自动从三档里取最长能整段放下的版本；
  - 右侧显示临时消息、`↑ 回看 N 行`、以及当前目录（来自 PowerShell / cmd 的 OSC 7）。
- 窗格内容区 = 第 1 行到倒数第 2 行，所以每个窗格的可视行数比窗口少 2 行。

## 窗格退出

窗格里的程序退出后，窗格不会立即消失，会保留最后输出并显示退出状态；可以用命令面板关闭该窗格，或直接关闭整个标签。
