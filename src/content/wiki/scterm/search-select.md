## 回看缓冲

每个窗格默认保留 10000 行回看（`scrollback` 可改）。

| 操作 | 方式 |
|---|---|
| 逐行回看 | 滚轮，或 `Ctrl+Alt+↑` / `Ctrl+Alt+↓` |
| 翻页 | `Shift+PageUp` / `Shift+PageDown` |
| 回到最新 | `Ctrl+Shift+End` |
| 应用占用鼠标时强制回看 | 按住 `Shift` 再滚轮 |

- 回看期间状态栏显示 `↑ 回看 N 行`。
- 窗格最右侧有滚动条：平时隐藏，悬停或回看时出现，可以直接拖动；即使子进程开启了鼠标上报也能拖。
- 有按键输入时会自动回到最新输出。

## 搜索

1. `Ctrl+Shift+F` 打开搜索；
2. 输入关键字，匹配范围是「回看缓冲 + 当前屏幕」；
3. `Enter` / `Shift+Enter` 在命中之间上下跳，视图会自动滚到命中的行；
4. `Esc` 关闭搜索并回到最新输出。

命中行用反色高亮，当前命中加粗。

## 鼠标选择与复制

| 操作 | 效果 |
|---|---|
| 拖动 | 线性选择 |
| 双击 | 选中一个单词（字母、数字与常见路径字符） |
| `Shift+点击` | 扩展已有选区 |
| `Ctrl+Shift+C` | 复制选区 |
| `Esc` | 清除选区 |
| 右键 | 粘贴（与 Windows Terminal 一致） |
| `Ctrl+Shift+V` | 粘贴；内容含多行时先弹确认 |

- 设置里打开「选中即复制」后，松开鼠标即写入剪贴板。
- 粘贴默认使用括号粘贴（`?2004`）包裹，避免多行命令被逐行执行。
- 子进程通过 OSC 52 请求写剪贴板时，会写入系统剪贴板。
- 输出里的 OSC 8 超链接：`Ctrl+点击` 用系统默认程序打开。

## 标记模式（纯键盘选择）

`Ctrl+Shift+M` 从光标处开始选择，不需要鼠标：

| 按键 | 作用 |
|---|---|
| 方向键 | 移动选区头 |
| `Ctrl+←/→` | 按单词移动 |
| `Home` / `End` | 行首 / 行尾 |
| `Ctrl+Home` / `Ctrl+End` | 缓冲首 / 尾 |
| `PageUp` / `PageDown` | 按可视高度移动 |
| `Enter` | 复制并退出；没有选中文本时提示 |
| `Ctrl+Shift+C` | 复制并退出 |
| `Esc` | 取消并退出 |

- 选区头移出视口时会自动滚动跟随。
- 鼠标点击、拖动或滚轮会退出标记模式；再次按 `Ctrl+Shift+M` 也可退出。

## 矩形（块）选择

- `Alt+左键拖动` 创建矩形选区；
- 复制时按列区间取值，**保留矩形内的空格**，行间用 CRLF；
- 即使子进程开启了鼠标上报，`Alt+左键` 仍然优先做块选择；
- 普通拖动、双击、`Shift+点击` 的行为不受影响。
