## 界面一眼看懂

```
 1:powershell  ×   2:cmd  ×    [ + ]        ← 顶部标签栏
┌──────────────────────┬──────────────────┐
│                      │                  │
│       窗格 A          │      窗格 B       │  ← 内容区
│                      │                  │
└──────────────────────┴──────────────────┘
 Ctrl+B 新建 · Ctrl+S 设置 · …              ← 底部状态栏
```

- **标签栏**：当前标签反色，每个标签末尾有 3 列宽的 `×` 关闭按钮，`+` 新建标签。
- **状态栏**：左侧是常驻快捷键提示，右侧显示临时消息、回看偏移和当前目录。
- 窗格内容区 = 第 1 行到倒数第 2 行。

## 五分钟走一遍

1. **打开一个标签**：`Ctrl+B`；想指定 profile 用 `Ctrl+Shift+B`，或在标签栏 `Alt+点 +`。
2. **分屏**：左右分 `Alt+Shift+-`，上下分 `Alt+Shift+加号`；`Alt+方向键` 在窗格间移动焦点。
3. **跑命令**：默认是 PowerShell，直接输入即可。退出 shell 后窗格会保留最后的输出。
4. **找东西**：`Ctrl+Shift+F` 搜索回看缓冲，`Enter` / `Shift+Enter` 上下跳命中，`Esc` 关闭。
5. **改外观**：`Ctrl+S` 打开设置，`↑↓` 选行、`←→` 改值，`Enter` 保存、`Esc` 还原。
6. **退出**：关闭最后一个标签。正常退出会把标签、布局、焦点写进 `session.toml`，下次启动自动恢复。

## 三个常用动作

| 想做的事 | 做法 |
|---|---|
| 找一个不记得快捷键的动作 | `Ctrl+Shift+P` 打开命令面板，输入中文名或动作 id |
| 复制屏幕上的内容 | 拖动选择后 `Ctrl+Shift+C`；也可以在设置里打开「选中即复制」 |
| 看到很久以前的输出 | 滚轮上滚，或 `Ctrl+Alt+↑`；`Ctrl+Shift+End` 回到最新 |

## 会话恢复

正常退出后，下次启动会恢复：

- 标签数量与顺序；
- 每个标签的窗格布局与分隔比例；
- 焦点窗格与活动标签；
- 自定义标签标题。

不会恢复窗格里正在运行的程序——窗格会重新启动。想关闭这个行为，在配置里设 `restore_session = false`。
