## 设置登录 Shell

「会话与登录 → 设置登录 Shell」一键在几个选项之间切换：

| 选项 | 登录后进入 |
|---|---|
| `cmd` | 命令提示符 |
| 自动进 `sconfig` | 服务器配置菜单（选 15 可进 PowerShell） |
| 轻量启动器 | 工具自带的 launcher 面板 |
| `explorer` | 桌面 Shell |
| 恢复原值 | 回到切换前的设置 |

**改动前会自动导出注册表备份**，随时可以还原。

> [!NOTE]
> sconfig 这条走的是一个批处理包装（`system32\servercoreshelllaunch.bat`），因为 Winlogon 用 `CreateProcess` 拉起登录 Shell，**不能直接执行 `.bat`**。

## 开机自动登录

「开机自动登录」有状态 / 启用 / 关闭三个动作。

关键点：**密码写进 LSA 机密，不是注册表明文**。实测闭环：写入 LSA → 真实重启 → 自动登录为 `console` 会话 → GUI 能力自检完整通过（整屏截图非黑占比 98.2%）。

> [!IMPORTANT]
> 卸载工具或换机器前，请先在工具里把自动登录**关掉**，否则会在注册表和 LSA 里留下自动登录配置。

## 远程会话一键修复

远程桌面连不上、或者连上后行为异常时用它。这里有个实测的坑：

**不能按英文 `DisplayGroup` 去找防火墙规则** —— 中文系统上组名是本地化的（「远程桌面」），按英文名匹配会一条都找不到。工具现在按本地化的组名匹配。

## 状态查询

同一组里还有几个纯查询动作，用来快速确认环境：

- **RDP / 会话 / UAC / .NET 状态**：一次把四类关键状态列出来
- **查询自动登录状态**：当前是否启用、账号是谁
