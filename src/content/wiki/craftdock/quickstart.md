## 第一步：新建实例

主菜单进入「实例」，选「新建」，依次填：

1. **实例名** —— 只用于界面显示，建议用英文或数字，避免路径里的空格；
2. **服务端核心** —— Paper / Purpur / Fabric / Forge / NeoForge / 原版；
3. **游戏版本** —— 例如 `1.21.4`，列表来自镜像站的实时数据；
4. **构建号** —— 有多个构建时可选，默认最新。

确认后程序会自己完成下载、解压、写入基础配置。

## 第二步：绑定 Java

实例创建完成后会提示选择 Java：

- 本机已经装了 Java，会直接列出来，选一个即可；
- 没有合适的版本，选「下载 Java」，从 MSL JDK 镜像拉取对应版本，下载完自动解压并绑定。

> 版本越高要求的 Java 越高：1.17 及以上至少 Java 17，1.20.5 及以上至少 Java 21；
> 更新的版本可以用镜像站里的 Java 25。

## 第三步：启动

在实例上按 `Enter` 进入实例页，选「启动」。第一次启动会生成世界，控制台会刷一大段日志，
最后出现 `Done!` 就表示服已经起来了。

## 第四步：日常操作

| 想做的事 | 操作 |
|---|---|
| 看控制台 / 发指令 | 实例页下方的终端，直接输入后回车 |
| 停止 | 实例页选「停止」，会发送 `stop` 并等待正常退出 |
| 改端口 / 内存 | 「设置」里改，启动参数与 `server.properties` 会一起更新 |
| 装模组 / 插件 | 「游戏资源」，见[游戏资源与镜像下载](../resources/) |
| 备份 | 「备份」→ 新建，世界和配置一起打包 |

## 没有 `Done!` 怎么办

按顺序看三件事：

1. **Java 版本对不对** —— 版本不匹配通常报 `Unsupported class file major version`；
2. **端口是否被占用** —— 报 `Address already in use` 就换个端口；
3. **内存是否太小** —— 报 `OutOfMemoryError` 就在设置里加大 `-Xmx`。

实例页的终端会保留完整输出，崩溃后的报错原文可以往上翻。
