## 停止实例后控制台出现一堆报错

旧版本在没有 PTY 的环境里会把字面量 `^C` 直接写进控制台，Paper 收到后当成非法输入。
现在停止命令默认是 `stop`，创建实例时也会自动纠正；如果你之前手动设过 `^C`，改成 `stop` 即可。

## 装好的插件只有几 KB，游戏里也不认

大概率下载到的是错误页而不是 jar。镜像站对 UA 有要求，拿不到文件时会返回一个 1 KB 左右的 HTML。
现在程序在下载前会先试读文件头，探测失败就换源；如果你手里有这种坏文件，删掉重装一次即可。

## 列表里有些资源点了没反应

那是**外部托管**的资源：文件实际放在 GitHub 之类的地方，源站只给一个跳转页。
这类条目不能直接落盘成 jar，程序会提示你用浏览器打开对应页面，下载后手动放进 `plugins/`。

## 窗口太小，提示看不全

程序会自适应：高度不足时状态栏压成一行、内容区上移。
但信息量摆在那里，建议`mode con: cols=120 lines=36`（`start-craftdock.bat` 已经帮你做了）。
终端字体建议用等宽字体，中文才不会错位。

## 启动就报 Java 版本不对

服务端版本和 Java 版本要匹配。到「Java」页看当前绑定的是哪个版本，
不够就下载对应版本再绑定；换 Java 后需要重启实例。

## 端口被占用

实例创建时会从 `server.properties` 同步端口。改端口要同时改设置里的端口和 `server.properties`，
改完重启；报 `Address already in use` 说明这台机器上还有别的进程占着这个端口。

## 实例目录能直接备份吗

可以。程序只是把实例当成一个目录管理，直接复制 `data/instances/<实例名>/` 出来就是完整存档。
界面里的「备份」只是帮你打包、加时间戳、方便恢复。
