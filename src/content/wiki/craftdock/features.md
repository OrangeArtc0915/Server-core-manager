## 页面一览

| 页面 | 能做的事 |
|---|---|
| 实例 | 新建、启动、停止、删除实例；查看控制台输出 |
| Java | 扫描本机 Java、从镜像下载 JDK、给实例绑定或解绑 |
| 文件 | 浏览实例目录，上传、下载、解压、压缩、删除 |
| 游戏资源 | 推荐模组/插件、搜索、一键安装、启用/禁用 |
| 备份 | 打包世界与配置，列出、恢复、删除 |
| 玩家 | 白名单、OP、封禁列表的增删 |
| 计划任务 | 定时重启、定时备份 |
| FRP | 三家服务商的令牌、隧道创建与启停 |
| 关于 | 版本、作者、QQ 群、友链 |

## 快捷键

功能再不一样，按键尽量保持一致：**删除永远是 `x`，下载永远是 `d`，上传永远是 `p`**，
不会出现「这里 `d` 是删除、那里 `d` 是下载」的情况。

| 按键 | 作用 |
|---|---|
| `↑` `↓` | 移动选择 |
| `Enter` | 确认 / 进入详情 |
| `Esc` | 返回上一层 |
| `x` | 删除（需要二次确认） |
| `d` | 下载 |
| `p` | 上传 |
| `u` | 解压 |
| `z` | 压缩 |
| `/` | 搜索 |
| `r` | 刷新列表 |
| `Space` | 启用 / 禁用（游戏资源） |
| `i` | 打开推荐列表 / 安装（游戏资源） |
| `[` `]` | 上一页 / 下一页（长列表） |

## 关于窗口大小

程序会按窗口高度自动调整：窗口足够高时状态栏显示完整提示，高度不够时压成一行，
内容区少占两行。建议 120 × 36 以上；更小的窗口也能用，只是提示和列表会滚动。

## 长列表的滚动

实例、Java、备份这类列表在条目超出可视区域时会出现滚动，顶部会提示当前范围
（例如 `1-12 / 34`），避免「东西明明在却看不见」。
