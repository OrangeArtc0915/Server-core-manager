## 为什么要装它

Server Core 没有 MMC 那一套图形管理工具（服务、事件查看器、磁盘管理、注册表…本质上都依赖 GUI 组件）。Windows Admin Center 是**微软官方的 Web 管理台**，用浏览器就能管这台机器。

本工具的「工具」页默认只列 7 个本机常用工具，另外 14 个管理类入口正是因为「装了 WAC 就不需要」而默认收起。

## 一键安装做了什么

1. **没本地安装包就自动下载**（`aka.ms/WACDownload`，约 140 MB，实测国内约 720 KB/s）
2. **自动识别两代安装包**：经典 MSI 用 `msiexec` + `SME_*` 参数；v2 用 Inno Setup 的 `/VERYSILENT`
3. **装完自动收尾**：放行防火墙、设为自启、启动服务
4. **探测入口是否可达**，最后输出浏览器访问地址
5. 全程通过 **SYSTEM 计划任务**执行

第 5 条不是洁癖：**v2 安装包会重启 WinRM**，如果直接在远程会话里装，你的会话会被切断、收尾步骤永远执行不到。放进 SYSTEM 任务里就不受会话影响。

## 实测记录

```text
[OK]   已安装: 版本 2.7.5.21   安装方式 v2 / Inno Setup 6.7.0
[INFO] 服务 WindowsAdminCenter    Running   启动=Auto
[INFO] 防火墙入站规则: 3 条
[OK]   /shell/ 探测: HTTP 302   网关响应正常
```

## 访问时的两个注意点

> [!IMPORTANT]
> 1. **入口是 `/shell/` 而不是根路径**。根路径返回 403 是登录页的正常状态码，不是坏了
> 2. HTTPS 用的是**自签名证书**，浏览器会警告，需要选择「继续访问」

装完访问不了？先跑「Windows Admin Center → 状态检查」，它会告诉你服务在不在跑、防火墙放行了没有、入口通不通。

## 离线 / 内网安装

用 `-NoDownload` 关掉自动下载，改用本地或内网的安装包。具体见[国内源与离线使用](../sources/)。

## 四个动作

- **状态检查**：版本、服务状态、防火墙、入口可达性
- **一键安装并自动配置**：上面那一整套
- **服务控制**：起停服务
- **打开界面**：直接用默认浏览器打开入口
