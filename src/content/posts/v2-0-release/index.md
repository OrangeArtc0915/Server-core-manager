这一版的重点是**界面重做**，以及把几个「点进去就报错」的页面修好。功能动作数量不变，仍然是 29 个。

## 界面重做，仍然只用 GDI+ / WinForms

界面按设计稿整体重做：无边框外壳（留白 + 自绘投影 + 12px 圆角卡片）、自绘标题栏与侧栏导航、矢量图标、语义化配色 Token。

约束没有变：**不依赖任何第三方 UI 库**，只用 GDI+ / WinForms —— 因为在 Server Core 上装不了桌面栈，任何依赖 WPF 或前端运行时的方案都会在第一步就卡住。

## 三个页面「点进去就报错」的根因

表现为：**仪表盘 / 安全 / AI** 三页一进去就报错。

根因是查询宿主的定时器回调用了 `.GetNewClosure()`。闭包会新建一个模块作用域，而回调里要调用的 `Update-GuiQueryHost` 是脚本里定义的函数 —— 在新建的模块作用域里**看不见**。

更麻烦的是它**只在「被别的脚本 `&` 调用」时发作**：直接 `powershell -File` 跑界面时脚本函数落在全局作用域，一切正常；而 `一键运行.bat` 走的正是 `&` 那条路。所以自检一直是绿的，双击就报错。

现在改成脚本级定时器 + 普通 scriptblock，并给自检与审计**补上这条调用路径**，避免再出现「自检全绿、双击报错」。

> [!NOTE]
> 同一类问题还有两个：`New-Pill` 里 `TextRenderer.DrawText` 的实参被逗号弄错位（表现是整站胶囊「有底色没字」）；「工具」页按钮的点击处理也用了闭包，只在真实启动链路下炸。现在都改成「参数放进控件 Tag + 普通 scriptblock」。

## 启动链路与编码

- 三个 `.bat` 启动器改为**纯 ASCII + CRLF**。cmd 是按「进程启动时的代码页」解析批处理的，中文会让它对不齐字节、把注释和 echo 的碎片当成命令执行 —— 表现是一屏「'xxx' 不是内部或外部命令」。`chcp 65001` 并不能解决这个问题
- 含中文的 `.ps1` 一律带 UTF-8 BOM（PowerShell 5.1 对无 BOM 文件按 GBK 解析，会乱码甚至语法错误）；`install.ps1` 反过来**不能**带 BOM，否则 `irm | iex` 会把 BOM 当成正文
- 必填参数为空时不再抛英文的参数绑定异常，改为明确提示**缺哪一项**
- 打开不存在的目录、机器上没有默认浏览器这类操作，以前会弹「JIT 调试」崩溃框；现在统一兜底并把详情写进 `logs\ui-error.log`

## 执行策略与终端提示

「一键美化终端」装完却毫无效果，原因通常是执行策略：Windows 客户端默认的 `Restricted` 会让 PowerShell 的 profile 加载不了，美化等于白装。现在安装时会检测并处理，还原时把原值放回去。

终端顶部那两行提示也改成**「有什么提示什么」**：

- `sconfig` / `scm` / `scm-term` 各自独立判断，有几个提示几个
- 之所以要改：上一版为了不提示不存在的命令，改成了「只提示真的装过的」—— 结果三个入口一个都没装时**一行都不显示**，看起来就像提示坏了
- cmd 与 PowerShell 两侧用同一套规则；cmd 侧只用 `if exist` 这类内建判断，绝不能出现外部命令或管道（AutoRun 挂在每个 cmd 实例上，管道会拉起子 cmd 再跑一遍 AutoRun，实测能把机器拖死）

## 窄屏

Server Core 常见分辨率是 1024×768，以前窗口比屏幕还大、右侧和底部被切，连缩都缩不小。

- 窗口尺寸改为跟随屏幕
- 仪表盘指标卡、美化页按钮在窄屏下会被裁掉（卡片挤成两行但容器只有一行高、按钮行不换行），已修
